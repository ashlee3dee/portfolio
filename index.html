Straight Skeleton & Wavefront Offset

A polygon offset tool built on a straight skeleton algorithm in my Blender node toolkit. An event queue implemented in Geometry Nodes handles edge collapses and polygon splits as the wavefront moves inward, tracing the skeleton along the way.
